v0.2.0

https://github.com/RyanStudioo/Parsegument/releases/tag/0.2.0

Main features:

You can now make commands via creating a child class of CommandGroup Added documentation for classes and their methods

Changes

Removed invalid commands raising Errors Arguments, Flags, and Operands now inherit from the base Parameter class

v0.1.1

https://github.com/RyanStudioo/Parsegument/releases/tag/0.1.1
This update focuses more on making Parsegument more convenient to use
Update Log:

  • Parsegumenter class and CommandGroup class now share a BaseGroup class
  • Command Decorator from BaseGroup class to automatically create Commands from functions
  • Parsegumenter.parse_string deprecated in favour of shlex.split() (also accessible via parsegument.split() now)
  • Pargusementer.execute() method now accepts lists and strings as inputs
  • Parsegumenter class now has an optional prefix and name
