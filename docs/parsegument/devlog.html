V0.3.0

https://github.com/RyanStudioo/Parsegument/releases/tag/0.3.0

Change Logs

Parsegument v0.3.0 adds functionality for CLIs, gives you more control over decorated commands, as well as providing help messages!

Added

CLI Functionality

  • Parsegument can now be ran in your terminal by running your script with python: 
    python script.py
  • You can then run your Parsegumenter with Parsegumenter().run()

Parameter Decorators

  • You can now modify parameter's types and help messages using: 
    @parsegument.argument()
@parsegument.flag()
@parsegument.operand()

Help Messages

  • Parsegument now returns help messages documenting subcommands, parameters and provided descriptions
  • Help messages can be triggered with the -help flag in any place of the command

Changes

  • BaseGroup().execute() and Command().execute() have been replaced by .forward() in order to distinguish it with Parsegumenter().execute()
  • BaseGroup and Command now inherit from a base CommandNode class in order to distinguish it from Parameter Nodes
  • Node class now has a help message attribute
  • arg keyword replaced with param in parameters and attributes

Bug Fixes

  • int datatypes now convert strings to a float before converting it to an int
