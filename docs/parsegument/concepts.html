Concepts

Argument Parsing

Parsegument uses the shlex module to parse arguments, where each argument is separated by spaces, and can be grouped using quotes

For example, the command:

git commit -m "this is a commit message"

would be converted into the following list:
["git", "commit", "-m", "this is a commit message"]

to use things like lists or dictionaries as arguments, you can use double quotes around them
command --list "[1, 2, 3]" --dict '{"key": "value"}'

read more about shlex at: https://docs.python.org/3/library/shlex.html

CommandGroups

CommandGroups are how Parsegument structures commands! CommandGroups can contain Commands, or even other CommandGroups

Commands

Commands are each linked to a specific function, and contains arguments
For example, the command 

git commit --m="this is a commit message"
would be a command called "commit"

Arguments

In Parsegument, there are 3 types of arguments:

  • Arguments
  • Flags
  • Operands

Arguments are compulsory inputs within a function
Flags are optional inputs to enable certain features, which are defined by a "-" before the argument
Operands are optional keyword arguments that are defined by a "--" before the argument

Examples

Here is how a Python function would be defined in Parsegument:

def my_function(arg1: int, arg2: str, flag: bool=False, operand: str="default"):
    pass

In the above function, arg1 and arg2 would be categorised as Arguments, meaning that they are compulsory
flag would be categorised as a Flag, meaning that it is optional, and can be enabled by using -flag
operand would be categorised as an Operand, meaning that it is optional, and can be set by using --operand=value

Here are some example commands that would execute the above function:
my_function 123 "hello world"
This command only fills in the compulsory arguments, and uses the default values for the optional arguments

my_function 123 "hello world" -flag
This command fills in the compulsory arguments, and enables the flag

my_function 123 "hello world" --operand="custom value"
This command fills in the compulsory arguments, and sets a custom value for the operand

my_function 123 "hello world" -flag --operand="custom value"
This command fills in the compulsory arguments, enables the flag, and sets a custom value for the operand
