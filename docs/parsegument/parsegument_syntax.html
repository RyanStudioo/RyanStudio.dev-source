Parsegument Syntax

Description

Parsegument's syntax differs from POSIX.1-2017 Chapter 12, in favour of something more consistent

Syntax

Arguments

Parameters without any "-" prefixes are arguments. These should be placed at the front and in order with the function
command param1 param2

Flags

a "-" prefix can only be used for flags, and can be of any length instead of just one letter
-flag1 -flag2

Operands

a "--" prefix can only be used for operands, with a "=" sign being the Operand's value
--operand1=value1 --operand2=value2

Examples

Original "git commit" command: 
git commit -m "insert commit message"
However, in Parsegument's syntax, it'd be: 
git commit --m="insert commit message"
