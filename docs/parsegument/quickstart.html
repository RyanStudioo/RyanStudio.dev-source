Quick Start

Setting up a Parsegumenter

It is recommanded to use a Parsegumenter Object as your main manager.
You can create one with the following:

import parsegument as pg
parser = pg.Parsegumenter() # Create Parsegumenter

Creating a CommandGroup

CommandGroups are how Parsegument groups commands! You can create a CommandGroup with the following:

group1 = pg.CommandGroup("group1") # Define a Group
parser.add_child(group1) # Add the Group to the main Parsegumenter
You can also create sub-groups by adding a CommandGroup to another CommandGroup

Defining your Command

Commands are each linked to a function. You can either define a command's arguments by using the @CommandGroup.command decorator, or defining it yourself with the Command.add_node() method

We'll be using the decorator for this example!

@group1.command
def foo(bar:str):
    print(bar)

Executing the Command

And... just like that, you're done! you can execute your comand with the following:

parser.execute("group1 foo bar_string")
This will print out bar_string to the console
You can add as many Commands and CommandGroups to the CommandGroup or Parsegumenter as you want!
