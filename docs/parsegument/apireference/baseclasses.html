Base Classes

Description

Base classes shouldn't be used directly. They are designed to be inherited by other classes to provide common functionality and structure.
They can, however, be used for type checking and typing hinting purposes

BaseGroup Class

Base class for Parsegumenter and CommandGroup.

Attributes

  • name (str) - The name of the BaseGroup.
  • children (dict) - A dictionary of children

Methods

  • BaseGroup._get_methods (classmethod)

    Returns a set of all non-dunder and non-private methods inside the class

    Parameters
    • cls (BaseGroup) - The class object.
    Returns

    set[str]

  • BaseGroup().add_child

    Adds a child to self.children if a node of the similar name has not been added

    Parameters
    • child (Union[Command, CommandGroup]) - The child you want to add
    Returns

    bool - Returns True if the child was added, False otherwise

Parameter Class

Base class for all parameters such as Arguments, Flags, and Operands

Attributes

  • name (str) - The name of the parameter.
  • arg_type (str) - The datatype of the parameter.
