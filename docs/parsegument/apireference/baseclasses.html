Base Classes

Description

Base classes shouldn't be used directly. They are designed to be inherited by other classes to provide common functionality and structure.
They can, however, be used for type checking and typing hinting purposes

parsegument.Node Class

The Base class for all Parsegument classes.

Attributes

  • name(str) - The name of the Node
  • help(Optional[str]) - The help message for the Node

parsegument.CommandNode(Node) Class

Inherited from Node Class
Used to distinguish Command and BaseGroup from Parameter

Attributes

  • name(str) - same as Node.name
  • help(Optional[str]) - same as Node.help

parsegument.BaseGroup(CommandNode) Class

Inherited from CommandNode class
Base class for Parsegumenter and CommandGroup.

Attributes

  • name(str) - same as Node.name
  • help(Optional[str]) - same as Node.help
  • children (dict) - A dictionary of children

Methods

  • add_child(child: Union[Command, CommandGroup])

    Adds a child to self.children if a node of the similar name has not been added

    Parameters
    • child (Union[Command, CommandGroup]) - The child you want to add
    Returns

    bool - Returns True if the child was added, False otherwise

Decorators

  • @BaseGroup().command(name: str=None, help: str=None)

    A Decorator that automatically creates a Command based on the function name, parameters, and their annotation, then adds it to self.children

    Parameters
    • name (str) - Replaces the name of the function
    • help (Optional[str]) - The help message for the function

parsegument.Parameter(Node) Class

Inherited from Node class
Base class for all parameters such as Arguments, Flags, and Operands

Attributes

  • name(str) - same as Node.name
  • help(Optional[str]) - same as Node.help
  • arg_type (type=str) - The datatype of the parameter.
