Command Decorators

These decorators automatically create a command based on the function's name, parameters, and annotations, then creates a Command

@CommandGroup().command(name: str = None, help: str = None)

@Parsegumenter().command(name: str = None, help: str = None)

Same as @BaseGroup.command()

Parameter Decorators

Overwrites any pre-made parameters after using Command Decorators

@parsegument.argument(name: str, arg_type: Optional[type]=None, help: str=None)

Overwrites any pre-made arguments with the defined argument

Parameters

  • name (str) - The name of the parameter
  • arg_type (Optional[type]) - Overrides the type of the parameter
  • help (str) - The help message

@parsegument.flag(name: str, help: str=None)

Overwrites any pre-made keyword arguments with the defined flag

Parameters

  • name (str) - The name of the parameter
  • help (str) - The help message

@parsegument.operand(name: str, arg_type: Optional[type]=None, help: str=None)

Overwrites any pre-made keyword arguments with the defined operand

Parameters

  • name (str) - The name of the parameter
  • arg_type (Optional[type]) - Overrides the type of the parameter
  • help (str) - The help message
