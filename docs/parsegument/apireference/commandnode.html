CommandNodes

Description

CommandNode is the base class used for Command and BaseGroup, it is used for any non-parameter nodes

parsegument.Parsegumenter(BaseGroup)

Inherits from BaseGroup
Main Manager for CommandGroup and Command
You should use this for execution, CLI running, as well as a general manager

Attributes

  • name (str) - Same as Node.name
  • children (dict) - stores Command or CommandGroup linked with the CommandGroup
  • prefix
    • (Optional[str]) - checks if an entered command begins with a certain prefix
  • help (Optional[str]) - Same as Node.help

Methods

  • execute(self, command:Union[str, list[str]]) -> Union[Any, None]

    Checks if a child with the name of the first list item exists, then executes the child
    It will also automatically check if it is valid with the prefix and name

    Parameters
    • command (Union[str, list[str]]) - Either a raw string of a command, or a list of parameters for a command
    Returns

    Any - returns any value returned by a function

  • run(self)

    Reads arguments from the terminal when running the python script, then performs Parsegumemter.execute on the input

parsegument.CommandGroup(BaseGroup)

CommandGroups are used to group Command and other CommandGroup together

Attributes

  • name (str) - Same as Node.name
  • children (dict) - stores Command or CommandGroup linked with the CommandGroup
  • help (Optional[str]) - Same as Node.help

Methods

  • initialise(self) -> None

    Only use this if creating a child class of CommandGroup
    This automatically creates Commands of methods added in a child class

    Returns

    None

parsegument.Command(CommandNode)

Inherited from CommandNode
Commands are linked to functions, and accept parameters

Parameters

  • name (str) - Same as Node.name
  • executable (Callable) - function that's executed when the command is called
  • parameters (dict) - Defined Arguments and Keyword Arguments of the Command
  • help (Optional[str]) - Same as Node.help

Methods

  • add_parameter(self, param: Union[Argument, Operand, Flag]) -> None

    Adds a parameter to the command

    Parameters
    • param (Union[Argument, Operand, Flag]) - The param you want to add to
    Returns

    None
