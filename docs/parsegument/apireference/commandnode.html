CommandNodes

Description

CommandNode is the base class used for Command and BaseGroup, it is used for any non-parameter nodes

parsegument.Command(CommandNode)

Inherited from CommandNode
Commands are linked to functions, and accept parameters

Parameters

  • name (str) - Same as Node.name
  • executable (Callable) - function that's executed when the command is called
  • help (Optional[str]) - Same as Node.help
